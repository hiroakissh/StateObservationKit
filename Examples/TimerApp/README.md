# Timer Example App

This executable sample composes the reusable `TimerExampleView` from the package.
It demonstrates:

- Observation-driven state transitions
- a cancellable application-layer ticker
- ordered `ObservationTraceRecorder` history
- the development-only `ObservationDebugOverlay`

Run it from the repository root with:

```bash
swift run StateObservationKitTimerExample
```
